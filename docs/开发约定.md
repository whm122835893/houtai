# 数字藏品后台 · 模块开发约定（供后续扩展/二次开发参照）

> 项目基于 **BuildAdmin v2.x**（ThinkPHP8 + Vue3 setup + TS + Element Plus + Pinia + Vite）。
> 本文档定义本模块的代码约定，新增页面请严格照此执行。

## 1. 目录与命名

| 层 | 路径 | 命名 |
|---|---|---|
| 控制器 | `app/admin/controller/nft/Xxx.php` | 命名空间 `app\admin\controller\nft`，类名大驼峰 |
| 模型 | `app/admin/model/nft/Xxx.php` | 命名空间 `app\admin\model\nft`，继承 `app\common\model\BaseModel`（含自动时间戳） |
| 验证器 | `app/admin/validate/nft/Xxx.php` | 命名空间 `app\admin\validate\nft`，`scene` 含 add/edit |
| API TS | `web/src/api/backend/nft/xxx.ts` | 从 `/@/utils/axios` 导入 `createAxios`，url 前缀 `/admin/nft.Xxx/` |
| 页面 | `web/src/views/backend/nft/xxx/index.vue` | `defineOptions({ name: 'nft/xxx' })`（与菜单 name 一致，用于 keepalive） |

## 2. 控制器约定

- 继承 `app\common\controller\Backend`，在 `initialize()` 中实例化 `$this->model`。
- 权限自动校验：路由为 `nft.控制器名/动作`（如 `nft.user/index`），对应 `ba_admin_rule` 中 name。
- 列表页统一使用自实现的简洁查询（不依赖 BaTable）：

```php
public function index(): void
{
    $keyword = $this->request->get('keyword/s', '');
    $status  = $this->request->get('status/d', -1);
    $limit   = $this->request->get('limit/d', 10);
    $page    = $this->request->get('page/d', 1);

    $where = [];
    if ($keyword !== '') $where[] = ['name', 'like', "%{$keyword}%"];
    if ($status >= 0)    $where[] = ['status', '=', $status];

    $total = $this->model->where($where)->count();
    $list  = $this->model->where($where)
        ->order('id', 'desc')
        ->page($page, $limit)
        ->select();

    $this->success('', ['list' => $list, 'total' => $total]);
}
```

- 新增/编辑：`$this->request->post()` 取数 → 验证器 → 事务 → `$this->success()`；删除走 `del` 动作，支持传 `ids` 数组。
- 金额：**入参元（decimal 字符串），落库分（bigint）**，用 `(int) bcmul($yuan, '100')`；返回给前端时输出分，前端负责 ÷100 展示。
- 时间：前端传 `YYYY-MM-DD HH:mm` 字符串时用 `strtotime()` 转时间戳；返回时间戳，前端用 `timeFormat` 格式化。
- 操作日志：写操作调用 `app\admin\model\nft\OperLog::record($module, $action, $target, $detail)`（静态方法内部取当前管理员与 IP）。
- 只读控制：页面写按钮由前端 `v-if="auth('nft/xxx/add')"` 控制；超管专用页（运营参数/数据清理）在控制器 `initialize()` 里 `$this->auth->isSuperAdmin()` 校验。

## 3. 前端页面约定

- 页面最外层：`<div class="nft-page">`（主题命名空间，见 `nft-glass.scss`）。
- 页头：`.page-head`（中文标题 + `.en` 英文小注）。
- 通用列表骨架：`.filter-bar.glass`（input/select/查询/重置）→ `.glass` 内 `.tbl-wrap > table.tbl` → `.pager`。
- 弹窗：自写 `.modal-mask` + `.modal.glass.pop`（不要用 el-dialog，保证玻璃质感）；危险操作用 `.modal` 内输入确认词或二次确认。
- 写权限：`import { auth } from '/@/utils/common'`，按钮 `v-if="auth('nft/xxx/add')"`。
- 请求：`import { createAxios } from '/@/utils/axios'`（实际用 `import createAxios from '/@/utils/axios'`，见现有 api 文件）；失败提示由 axios 拦截器自动处理，成功后 `ElMessage.success` / 刷新列表。
- 时间格式化：`import dateTimeFormat from '/@/utils/common'`（返回 `YYYY-MM-DD HH:mm`）。
- 金额展示：`<span class="serif-num">￥{{ (row.price / 100).toFixed(2) }}</span>`；输入金额用元，提交前 `Math.round(yuan * 100)`。
- 图片上传：`<el-upload :action="fileUpload.url" :headers="fileUpload.headers">`，其中
  `const fileUpload = useFileUpload()`（`/@/stores/constant`）→ `fileUpload.url`、`fileUpload.headers`；上传成功取 `res.data.file.full_url`。
- 富文本：使用 `Editor` 组件 `/@/components/editor/index.vue`，`v-model="form.detail"`。
- 进场动画：卡片加 `class="glass rise" :style="{ '--i': n }"`。
- 空态：`.empty > .glyph(emoji) + 文案`。
- 移动端：不要写死宽度；表格放在 `.tbl-wrap` 内自动横滚；筛选控件宽度用主题样式自动适配。

## 4. 菜单与权限

- 菜单/按钮已通过 `database/nft.sql` 写入 `ba_admin_rule`；新增页面需同步补 SQL。
- 页面 keepalive 依赖：菜单 `name` == 页面 `defineOptions.name` == 路由 path 形式 `nft/xxx`。

## 5. 主题

- 所有页面样式类（`.glass .btn .tbl .tag .input .select .stat-card .pager .empty .modal` 等）已在 `web/src/styles/nft-glass.scss` 定义，页面内不重复定义，只写少量页面私有样式（scoped）。
- 该文件需在 `web/src/styles/index.scss` 末尾 `@import './nft-glass.scss';` 引入。

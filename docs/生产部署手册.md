# 生产部署手册

> 更新时间：2026-11-12
> 适用：BuildAdmin 数藏后台（本仓库 main 分支）
> 姊妹篇：`docs/本地运行.md`（装配细节）、`docs/运维-定时任务与巡检.md`（定时任务/巡检/备份）

## 一、架构与路径约定

| 项 | 约定 |
|----|------|
| Web 根目录 | `public/`（SPA 静态文件 + ThinkPHP 入口同目录共存） |
| 后台访问 | `https://你的域名/admin`（hash 路由） |
| 后台 API | 同域名 `/admin/控制器/方法`，前端 axios 自动附加 `server` 参数区分前后端路由 |
| 部署目录示例 | `/www/wwwroot/buildadmin`（下文以此为准，按实际替换） |
| 构建产物链路 | `web/ npm run build` → `web/dist/` → 拷贝至 `public/`（**必须拷贝，否则线上跑旧代码**） |

## 二、服务器环境要求

| 组件 | 要求 | 备注 |
|------|------|------|
| PHP | >= 8.2，扩展：mbstring / pdo_mysql / gd / curl / xml / bcmath / zip / fileinfo | |
| 数据库 | **推荐 MariaDB 10.4+** | `database/nft.sql` 的增量 ALTER 使用 `ADD COLUMN IF NOT EXISTS`（MariaDB 语法）；用 MySQL 8 需把增量段 ALTER 逐条手改后执行（见第六节） |
| Node.js | 22.13+（仅构建期需要，服务器可不安装——本地构建后上传 `public/` 即可） | |
| Composer | 2.x | 用官方 packagist 源（阿里云镜像缺 topthink/framework 8.1.4，勿用） |

## 三、首次部署步骤

```bash
# 1. 代码
cd /www/wwwroot
git clone https://github.com/whm122835893/houtai.git buildadmin && cd buildadmin

# 2. 依赖（生产不装 dev 依赖）
composer install --no-dev --optimize-autoloader

# 3. 数据库（库名/账号自定，utf8mb4）
mysql -e "CREATE DATABASE nft DEFAULT CHARSET utf8mb4 COLLATE utf8mb4_unicode_ci;"

# 4. 环境配置 .env（PREFIX 必须留空！业务表为裸表名）
cat > .env <<'EOF'
[APP]
DEBUG = false

[DATABASE]
TYPE = mysql
HOSTNAME = 127.0.0.1
DATABASE = nft
USERNAME = nft
PASSWORD = 强密码
HOSTPORT = 3306
PREFIX =
CHARSET = utf8mb4
EOF
chmod 600 .env

# 5. 建表：先框架迁移，再业务扩展
php think migrate:run
mysql nft < database/nft.sql        # 幂等（IF NOT EXISTS），重复执行安全

# 6. 管理员密码（迁移种子密码未知，装完立即重置）
php think service:discover &        # 若提示无此命令可忽略
# 临时重置脚本见 docs/本地运行.md 第 6 步：Admin::resetPassword(1, '新密码')

# 7. 前端构建 + 发布（本地或 CI 构建后上传亦可）
cd web && npm ci && npm run build
cp -r dist/. ../public/
cd .. && echo 'install-end' > public/install.lock   # 防止触发安装向导

# 8. 目录权限
chown -R www:www . && chmod -R 755 . && chmod -R 775 runtime/
```

## 四、Nginx 配置样例

```nginx
server {
    listen 443 ssl http2;
    server_name 你的域名;
    root /www/wwwroot/buildadmin/public;
    index index.php index.html;

    # 静态资源直出，其余交给入口（入口自行区分 SPA 重定向与 API）
    location / {
        try_files $uri $uri/ /index.php$is_args$args;
    }
    location ~ \.php$ {
        fastcgi_pass unix:/tmp/php-cgi-83.sock;   # 按实际调整
        fastcgi_index index.php;
        include fastcgi.conf;
    }
    location ~* \.(js|css|png|jpg|svg|woff2?)$ {
        expires 7d;
        access_log off;
    }
    # 禁止访问敏感文件
    location ~ ^/(\.env|composer\.(json|lock))$ { deny all; }
}
# HTTP → HTTPS
server { listen 80; server_name 你的域名; return 301 https://$host$request_uri; }
```

## 五、上线前安全加固 Checklist（逐项打勾）

| # | 项 | 怎么做 |
|---|----|--------|
| 1 | 关闭调试 | `.env` 中 `[APP] DEBUG = false`（线上报错只记日志不回显） |
| 2 | 开启登录验证码 | `config/buildadmin.php` → `admin_login_captcha => true`（沙箱为 false，**上线必须改回**） |
| 3 | 改默认密码 | admin 初始 123456 → 强密码；后台「管理员管理」里操作 |
| 4 | install.lock | `public/install.lock` 必须存在（防重装清库） |
| 5 | HTTPS | 全站 301 到 https（微信支付/手机端硬性要求） |
| 6 | .env 权限 | 600，且 nginx 已 deny；**不要提交到 git** |
| 7 | 定时任务三件套 | 按 `scripts/crontab.example` 安装（维护/备份/巡检），详见运维手册 |
| 8 | 备份异地化 | `backups/` 在本机，需同步到对象存储/另一台机器，防整盘故障 |
| 9 | 限流确认 | `config/throttle.php` 框架限流已启用；C 端上线后关注 api 应用命中情况 |
| 10 | 巡检退出码 | `php think nft:check` 必须= 0 才算部署成功 |

## 六、MySQL 用户的增量脚本注意

`database/nft.sql` 末尾「增量」小节的 `ALTER TABLE ... ADD COLUMN IF NOT EXISTS`：
- **MariaDB**：直接执行，幂等
- **MySQL 8**：先 `SHOW COLUMNS FROM 表 LIKE 'deletetime'` 判断，不存在再执行去掉 `IF NOT EXISTS` 的 ALTER（涉及 collection/category/banner/notice/user/blindbox/raffle/lottery_activity 共 8 表）

## 七、版本升级流程

```bash
cd /www/wwwroot/buildadmin
git pull
composer install --no-dev --optimize-autoloader
mysql nft < database/nft.sql        # 增量表/权限，幂等
cd web && npm ci && npm run build && cp -r dist/. ../public/
php think nft:check && echo OK      # 巡检通过即升级完成
```

回滚：`git checkout 上一个tag/commit` → 重新构建 → 用 `backups/` 最近备份恢复数据库（如有结构变更）。
